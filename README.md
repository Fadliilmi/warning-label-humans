The safety warning label that should come printed on every human being, in a single line of at most 160 characters: funny first, plausible second. One true human flaw, one read, with the turn landing in the last few words — the fries never make it to the table, and the denial comes with the sauce still on the human's face.

> WARNING: This human eats the fries before reaching the table, then denies it with sauce still on their face.

## How to run

Requires Node 22 or later. No network access is needed at runtime.

```sh
node main.ts
```

This writes the single-line entry to `/output/entry.txt` (108 characters, one line, no trailing newline). `main.ts` validates the length itself and throws if the line is outside 1–160 characters or contains a newline.
